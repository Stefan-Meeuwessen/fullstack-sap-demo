# Introduction
This repo holds multiple examples of fetching data from SAP Datasphere towards PowerBI

## Options
1. SAP Datasphere <- PowerBI
2. SAP Datasphere <- Dataplatform <-> PowerBI
   - With a temp table
   - Streaming directly to PowerBI

## Structure
In this demo I have a PowerBI projects and a Notebook. The PowerBI project uses a connection with OData and ODBC. The Notebook uses JDBC.
